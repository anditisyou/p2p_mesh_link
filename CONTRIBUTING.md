# Contributing to AetherNet

Thank you for contributing to AetherNet.

## Getting Started
1. Fork the repository
2. Clone your fork
3. Create a new branch
4. Make your changes
5. Commit your changes
6. Push your branch
7. Open a Pull Request

## Guidelines
- Write clean and readable code
- Keep pull requests focused
- Follow existing project structure
- Test features before submitting

## Development Setup
npm install
npm run dev

## Reporting Bugs
Please create a detailed issue including:
- Steps to reproduce
- Expected behavior
- Screenshots/logs if available
