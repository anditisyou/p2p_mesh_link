# AetherNet — Prototype

AetherNet is a prototype decentralized emergency communication system designed to simulate peer-to-peer mesh networking without relying on centralized internet infrastructure.

The project demonstrates how devices can communicate directly using mesh networking concepts, distributed peer discovery, and packet routing mechanisms during infrastructure failures or emergency scenarios.

---

## Features

- Peer-to-peer communication simulation
- Mesh-based packet propagation
- Distributed Hash Table (DHT) concepts
- TTL-based routing system
- Packet rebroadcasting and deduplication
- Emergency SOS broadcasting
- Real-time network visualization
- Offline-first communication concepts
- Simulated encrypted communication flow

## Prototype Scope

This project is currently a frontend prototype and networking simulation.

It focuses on:
- decentralized communication concepts
- mesh routing behavior
- packet flow visualization
- distributed networking logic

The prototype is intended for learning, experimentation, and demonstrating how infrastructure-independent communication systems can work.
